# 🚀 The Simplest Full-Stack Template Ever

```
📱 FRONTEND              🔧 BACKEND              ☁️ EDGE
react-frontend/         workers-backend/         Cloudflare
├── pages/             ├── routes/api/          ├── D1 Database  
├── components/        ├── functions/           ├── R2 Storage
└── App.tsx           └── index.tsx            └── Workers
```

## ⚡ 3 Commands to Start

```bash
npm install    # Install everything
npm run dev    # Start developing → localhost:5173  
npm run deploy # Go live
```

## 📄 Add a Page (30 seconds)

1. **Create**: `src/react-frontend/pages/Cool.tsx`
```tsx
export default function Cool() {
  return <h1>My Cool Page!</h1>;
}
```

2. **Export**: Add to `src/react-frontend/pages/index.ts`
```tsx
export { default as Cool } from './Cool';
```

3. **Route**: Add to `src/react-frontend/App.tsx`
```tsx
<Route path="/cool" element={<Cool />} />
```

**Done!** Visit `http://localhost:5173/cool`

## 🔌 Add an API (1 minute)

1. **Create**: `src/workers-backend/routes/api/cool.ts`
```tsx
import { Hono } from 'hono';
const cool = new Hono();
cool.get('/', (c) => c.json({ message: 'So cool!' }));
export default cool;
```

2. **Export**: Add to `src/workers-backend/routes/index.ts`
```tsx
export { default as cool } from './api/cool';
```

3. **Mount**: Add to `src/workers-backend/index.tsx`
```tsx
import { cool } from './routes';
app.route('/api/cool', cool);
```

**Done!** Visit `http://localhost:5173/api/cool`

## 💾 Database Operations (D1)
```tsx
// In your API route handler:
const users = await c.env.DB.prepare('SELECT * FROM users').all();
const user = await c.env.DB.prepare('SELECT * FROM users WHERE id = ?').bind(userId).first();
```

## 📦 File Operations (R2)
```tsx
// Upload file:
await c.env.ASSETS.put('file.jpg', fileData);

// Download file:
const file = await c.env.ASSETS.get('file.jpg');
```

## 🔌 Setup D1/R2 Remote Bindings
1. **Create D1**: `npx wrangler d1 create mydb` 
2. **Update `wrangler.json`** with real database/bucket IDs
3. **Add remote flags**: `"experimental_remote": true`
4. **Enable in Vite**: `vite.config.ts` → `remoteBindings: true`
5. **Apply schema**: `npx wrangler d1 execute mydb --file=./schema.sql`

## 🎯 That's It!

- **Frontend**: React + Router in `react-frontend/`

- **Database**: D1 ready in `wrangler.json`

- **Deploy**: `npm run deploy`

Everything else is just details. This template makes full-stack **stupidly simple**.
